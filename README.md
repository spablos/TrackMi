# TrackMi

אפליקציית ווב אישית לטלפון: מעקב אימונים, תכנון תזונה שבועי, שתייה, שינה, משקל, תמונות מעקב ואתגר ימים.

## מה יש באפליקציה

| # | מסך | מה עושים בו |
|---|-----|-------------|
| 1 | היום | אתגר הימים עם המשימות של היום, שתייה בכוסות, שעות שינה, משקל, הארוחות והאימון של היום |
| 2 | אימונים | תוכנית שבועית, תרגילים עם סטים/חזרות/משקל, סימון "בוצע", תבניות לשימוש חוזר, העתקת שבוע קודם |
| 3 | תזונה | תפריט שבועי לפי ימים וארוחות, קלוריות וחלבון/פחמימה/שומן מול היעד, ספריית מזונות שמתמלאת לבד |
| 4 | מדדים | גרף משקל מול יעד, שתייה ושינה ב־14 הימים האחרונים, תמונות מעקב עם השוואת התחלה מול אחרונה |
| 5 | אתגר | כמה ימים נשארו, לוח ימים צבעוני, רצף, אחוז הצלחה, משימות ידניות או אוטומטיות (מים, שינה, אימון, קלוריות) |

היעדים (קלוריות, מאקרו, מים, גודל כוס, שינה, משקל יעד) משתנים מכפתור ההגדרות בפינה.

## איפה הנתונים נשמרים

הכול נשמר **על הטלפון בלבד** (localStorage לנתונים, IndexedDB לתמונות). אין שרת ואין חשבון.
לכן כדאי מדי פעם: הגדרות ← **ייצוא גיבוי**, ולשמור את הקובץ בענן. שחזור נעשה מאותו מקום.

## העלאה לאוויר עם GitHub Pages

1. ב־GitHub: Settings ← Pages.
2. תחת Build and deployment בוחרים Source: **Deploy from a branch**, Branch: **main**, תיקייה **/ (root)**, ושומרים.
3. אחרי דקה בערך האתר זמין בכתובת `https://spablos.github.io/TrackMi/`.

הערה: GitHub Pages ברפוזיטורי פרטי דורש מנוי GitHub Pro. בחשבון חינמי אפשר להפוך את הרפוזיטורי לציבורי (הנתונים האישיים לא נמצאים בקוד, רק בטלפון), או לחבר אותו ל־Netlify / Vercel / Cloudflare Pages בחינם.

## התקנה בטלפון

- **iPhone (Safari):** פותחים את הכתובת ← כפתור השיתוף ← "הוספה למסך הבית". חשוב להשתמש תמיד באייקון שבמסך הבית, כי ב־iPhone לאפליקציה מהמסך הבית יש אחסון נפרד מ־Safari.
- **Android (Chrome):** פותחים את הכתובת ← תפריט ⋮ ← "התקנת אפליקציה".

אחרי ההתקנה האפליקציה עובדת גם בלי אינטרנט.

## מבנה הקבצים

```
index.html            מבנה הדף והניווט
styles.css            עיצוב (בהיר/כהה לפי הטלפון)
app.js                כל הלוגיקה והמסכים
sw.js                 עבודה בלי אינטרנט (מטמון)
manifest.webmanifest  הגדרות ההתקנה כאפליקציה
icons/                אייקונים
```

אין שלב build. כדי לבדוק מקומית: `python3 -m http.server` ולפתוח `http://localhost:8000`.
אחרי שינוי בקבצים כדאי להעלות את המספר ב־`CACHE` בתוך `sw.js`, כדי שהטלפון יקבל את הגרסה החדשה.
